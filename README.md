# Hacker Tools Overview — SANS SEC504

A single-page, searchable reference of the hacker, exploitation, and incident-response tools taught in **SANS SEC504 — Hacker Tools, Techniques, and Incident Handling**.

Open `index.html` in any browser, or host it with GitHub Pages.

## Features

- **30 tools** across reconnaissance, scanning, password attacks, web/API attacks, post-exploitation, persistence, network investigation, and live Windows/PowerShell investigation.
- **Search by name or tag**, plus clickable tag filters (the first four show under the search bar; a `…` toggle reveals the rest).
- Each tool card carries a short summary, **example commands with an inline explanation of each**, and a collapsible **Flags and Options** reference written in plain language.
- Light/dark theme aware, responsive down to phone width.

## Usage & disclaimer

These are legitimate, publicly documented security tools for **authorized testing, incident response, and defense only**. Use them only on systems you own or have written permission to test. Example commands and flag descriptions reflect standard documented usage, not SANS courseware.
